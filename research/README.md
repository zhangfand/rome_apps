# Research

A home for research that takes weeks, not one chat. Each topic keeps its conversations, material and notes together, so every new conversation starts from where the last one left off.

## What it does

- **Topics with a living brief** — each topic has a short status page (the question, where your thinking stands, what's still open) that the research agent reads before every conversation and keeps up to date.
- **Conversations that don't get lost** — chats started from a topic are archived automatically after every turn: a running summary plus the full transcript.
- **Material of any kind** — save links, PDFs, code repositories, images or pasted text. Pages and PDFs are downloaded and their text extracted so they stay searchable.
- **Notes** — capture insights and comparisons as you go, or let the agent write them.
- **Search everything** — find a phrase across briefs, notes, conversation records and saved material.
- **Plain files** — everything is ordinary Markdown and files in a folder, so you can open it in Obsidian or keep it in git.

## When to use it

- Following a technical field over months (for example, agent memory systems).
- Evaluating options where the reasoning matters as much as the conclusion.
- Any question you keep coming back to and don't want to re-explain each time.
